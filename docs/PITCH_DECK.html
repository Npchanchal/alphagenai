The problem

Analysts remember guidance. Markets punish missed promises.

Anecdotal memory

Buy- and sell-side track “management always guides high” in notebooks and Slack — not in a longitudinal, auditable score.

Wrong product category in India

Local tools score sentiment, ratios, and estimates. They stop before did they deliver on what they said?

Global trackers miss India

Marvin Labs / FinCatch prove the category on US/SEC workflows. NSE/BSE formats and mixed-language concalls need a local spine.

When credibility is anecdotal, conviction sizing and note quality suffer — especially into earnings.

Solution

Guidance Credibility Index (GCI)

Extract quantified promises → match to actuals → score 0–100 with a full evidence trail.

01

Extract

Metric, band, period, speaker from filings & concalls.

02

Match

Link each statement to subsequent reported actuals.

03

Score

Met / exceeded / missed / dropped / pending → company GCI.

04

Compound

Analyst Accept / Edit / Reject grows the labeled corpus.

Every score point traces to guidance statement + actual (date, metric, source).
