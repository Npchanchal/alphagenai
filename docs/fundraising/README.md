Every equity deck uses the same split. Only the rupee total changes.

- **45%** labeling and review, until Sensex 30 and Nifty 50 are at established depth (public target **31 March 2027**).
- **35%** founder-led design partners. A seller is hired after three desks are in a pilot.
- **20%** inference, hosting, securities counsel, company secretary.
